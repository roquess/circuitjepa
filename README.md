# CircuitJEPA

CircuitJEPA (a fully circuit-based Joint-Embedding Predictive Architecture)
explores a JEPA implemented entirely on quantum circuits. Built with Qiskit and PyTorch, it learns to predict the latent
representation of future states of a small spin system directly in the quantum
domain.

Status: work in progress.

Paper: [CircuitJEPA: a fully circuit-based Joint-Embedding Predictive Architecture for quantum dynamics](paper/circuitjepa.md) ([PDF](paper/circuitjepa.pdf)).
